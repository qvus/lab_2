# Лабораторная работа № 2 — вариант 15

Репозиторий: https://github.com/qvus/lab_2

Консольная программа проверяет и ищет канонические двоичные записи чисел,
кратных трём. Данные можно вводить вручную, читать из файла или загружать
с веб-страницы по HTTP/HTTPS.

## Запуск

Нужен Python 3.10 или новее. Внешние библиотеки не используются.

```sh
make run
```

Чтобы проверить пример из `examples/sample_text.txt`, выберите пункт 3 меню и
введите путь `examples/sample_text.txt`.

## Проверка

```sh
make test
```

## Как устроен проект

- `triple_scan/binary.py` — регулярное выражение, проверка и поиск записей.
- `triple_scan/text_sources.py` — чтение файлов и извлечение текста из HTML.
- `triple_scan/cli.py` — консольное меню и обработка пользовательских ошибок.
- `tests/` — проверки логики поиска и чтения источников.
- `examples/` — небольшой файл для ручной демонстрации.
- `docs/` — отчёт по лабораторной работе.
